# Verification

Verify the real artifact, not merely a successful tool response.

## Phone wallpaper

- Correct portrait ratio and actual dimensions reported.
- Main theme is legible before decorative motifs.
- Optional foreground anchor stays within the approved frame share.
- Status-bar area has usable breathing room when relevant.
- Repeated motifs vary in scale and create depth instead of clutter.
- No malformed text, accidental brands, signatures, or watermarks.
- Style matches the approved geometry, materials, palette, light, rendering, and mood.

## Desktop wallpaper

- True landscape recomposition; no stretched geometry or obvious portrait crop.
- Focal point and recurring motifs remain readable at desktop viewing distance.
- Important content stays away from extreme edges.
- A useful negative-space region exists if the user wants room for icons.

## Tablet wallpaper

- True tablet recomposition and correct requested orientation.
- Main subjects remain inside a safe central region for minor system cropping.
- Visual weight is balanced across the wider frame.

## Dynamic wallpaper

Inspect the beginning, middle, and end, then review the loop boundary.

- First and last composition match closely enough for the intended loop.
- Camera remains fixed unless movement was approved.
- Motion is subtle, scene-native, and low amplitude.
- Buildings, roads, screens, characters, and recurring motifs do not warp, duplicate, disappear, or change identity.
- Small text and screen graphics do not mutate distractingly.
- No unintended cuts, flashes, exposure jumps, subtitles, logos, or audio.
- Actual duration, dimensions, ratio, codec/container, and file path are reported.

If the loop is imperfect, describe the visible discontinuity. Do not call it seamless.
