# Style analysis

Use this reference when the user supplies visual references or asks to reverse-engineer a style.

## Analyze the set, not just individual images

Verify that every promised reference is available and readable before drawing conclusions. Inventory the complete set and group it by visual consistency. Select a dominant cluster from repeated evidence. Mark images as variants or outliers when they materially change rendering, palette, density, era, or composition.

Extract the following style DNA:

| Dimension | What to identify |
|---|---|
| Medium and era | photography, illustration, early CGI, clay, pixel art, architectural visualization, film era |
| Geometry | primitive or complex forms, hard or rounded edges, proportions, scale relationships |
| Materials | plastic, ceramic, paper, metal, glass, matte, glossy, textured, flat |
| Palette | dominant neutrals, supporting hues, accent colors, saturation and contrast |
| Lighting | time of day, source direction, softness, shadow color, glow and haze |
| Composition | viewpoint, horizon, foreground share, depth layers, symmetry, leading lines, sky or negative space |
| Motifs | repeated props, architecture, vegetation, screens, symbols, characters |
| Rendering | realism, detail level, lens behavior, grain, scanlines, softness, banding |
| Atmosphere | calm, uncanny, playful, nostalgic, clinical, dreamy, crowded, empty |
| Typography | whether text is structural, decorative, absent, readable, or intentionally abstract |

## Separate style from content

Rewrite observations as transferable rules. For example:

- Content observation: “a large television sits on the left.”
- Transferable style rule: “one modest retro electronic object anchors the foreground, with smaller repeated versions creating depth.”

Do not carry over distinctive characters, real brands, logos, creator signatures, or exact layouts unless requested.

## Output format

Deliver four blocks:

1. **Style diagnosis:** one or two sentences naming the useful visual combination in plain language.
2. **Style DNA:** the stable rules, followed by optional variants.
3. **Style-board prompt:** a prompt for a coherent multi-panel board showing the same style across varied scenes.
4. **Negative prompt:** the nearby styles and failure modes that would dilute the target.

If the references contain more than one plausible direction, show the alternatives and recommend the direction best supported by the set. Do not silently merge them.

## Style-board prompt requirements

Create this prompt when the user wants a reusable style board or is continuing into wallpaper generation. The board prompt should:

- request 6–9 panels or another compact grid;
- vary scene and composition while holding medium, geometry, materials, palette, light, and mood constant;
- include close, medium, and wide examples when useful;
- avoid captions, labels, brands, watermarks, and creator names;
- state that the board is for art direction, not a collage of the supplied images.
